# Flint & Quill — Website

Static website for Flint & Quill, a Texas-based back-office services firm offering bookkeeping for home-services contractors and medical billing for clinics (coming soon).

## Pages

- **index.html** — Home: hero, Clean-Up Special, monthly bookkeeping, how it works, security, medical billing teaser
- **bookkeeping.html** — Full bookkeeping services detail, pricing, guarantee
- **medical-billing.html** — Medical billing for PT clinics (coming soon / pilot program)
- **about.html** — Firm story, team, values
- **contact.html** — Free consultation form (mailto-based)
- **style.css** — Shared stylesheet
- **script.js** — Mobile nav toggle, mailto form handler

## Preview Locally

Open `index.html` directly in a browser, or run a local server:

```
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
